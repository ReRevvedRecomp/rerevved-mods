## About

This repository contains mod source, manifests, shared build support, and
package tooling. The title API mirror and ReXGlue SDK dependency
are pinned by `rerevved-api.lock.json` and `rexglue-sdk.lock.json`.

Retail game files and extracted assets are not distributed by this project.
Title behavior and reusable runtime facilities remain in their owning
repositories.
