## Install

Every [ReRevved release](https://github.com/ReRevvedRecomp/rerevved/releases) already includes these mods. Press F2 in
the game to enable them, select **Save changes**, and restart.
[Mods](https://github.com/ReRevvedRecomp/rerevved/blob/main/docs/mods.md) covers load order and installing other
packages.
